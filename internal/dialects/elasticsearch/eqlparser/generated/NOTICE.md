# Generated EQL grammar

These Go files are generated from Elasticsearch's `EqlBase.g4`, pinned to the
8.19.21 and 9.1.10 commits recorded in
`tools/es-language-parser/manifest.json`. The upstream grammar is identical in
those two profiles. The grammar and generated files retain the upstream Elastic
License 2.0 notice; the complete license is in
`tools/es-language-parser/upstream/LICENSE-Elastic-2.0.txt`. They are not covered
by the repository's MIT license. ANTLR's Go runtime is a separate BSD-licensed
module dependency. See `tools/es-language-parser/README.md` for regeneration.
